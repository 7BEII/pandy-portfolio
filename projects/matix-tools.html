AIGC 生产工具

Matix Tools

把创作流程，装进一个工作台。

按这个顺序讲：结论、能力、步骤、画面

多模型生成、批量任务与图像编辑，让创意从一次尝试走向持续生产。

创作时，提示词、模型参数、任务进度和生成结果常常散落在不同入口。我把这些操作组织到同一个工作台中，让使用者能从一个想法开始，完成生成、处理和归档。

参与角色
产品规划 / 交互设计 / Python 开发
技术与方向
Python / 多模型接入 / 任务调度 / Electron

已在公司同事的实际工作中使用，并形成 Windows 桌面安装包。

01

统一模型入口

集中管理图片与视频生成入口，根据模型能力处理参考图、比例和清晰度等参数。

任务需要有记忆

保留任务输入和参数，让失败后重试与历史结果回溯有明确依据。

02

让批量任务可控

查看排队、运行与失败状态，管理批量任务和重试，把输入参数与结果对应起来。

界面与调用保持一致

模型选择、后端能力和实际调用记录一致，减少参数误用。

03

延续创作过程

从生成画廊进入 PHOTO plus，进行图层、蒙版、文字与多画板编辑，再保存工程或导出。

做成可以交付的工具

Electron 桌面外壳配合 Python 后端，提供安装、启动与持续维护的完整体验。

让每一步都有清晰的去向。

从输入到产出，保留必要的检查、状态与记录。
