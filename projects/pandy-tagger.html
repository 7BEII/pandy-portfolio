图像打标与训练辅助

Pandy Tagger

让训练数据，准备得更顺手。

把图像、标签、训练配置和分析放到一条清晰的工作路径上。

训练之前，大量精力会花在选图、打标、修改标签和核对配置上。Pandy Tagger 围绕这些真实操作构建工作台，帮助用户把素材整理为更容易检查和使用的训练数据。

参与角色
产品设计 / 数据处理 / Python 开发
技术与方向
Python / 图像打标 / 数据集 / LoRA

已提供给外部客户使用，围绕图像打标与训练准备持续迭代。

01

图像与标签一起管理

支持单图及 R/T/G 图片组，进行 Caption 编辑、批量 AI 打标、取消与失败项重试。

让文件和界面保持同步

图像和 TXT 的编辑反映到本地数据集，降低重复导入、导出和版本混淆。

02

把检查前移到训练之前

核对图像配对与标签，生成和编辑训练 YAML，保持界面数据与本地文件同步。

让用户掌握修改范围

批量操作提供状态与失败项处理，保留人工校对和选择的空间。

03

读懂训练留下的记录

查看 Loss 曲线、历史记录与 checkpoint 候选，再结合样图判断模型效果。

让分析服务于判断

用训练曲线和记录辅助选优，最终结合视觉样张考察人物、风格和稳定性。

让每一步都有清晰的去向。

从输入到产出，保留必要的检查、状态与记录。
