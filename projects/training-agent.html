数据集与训练流程编排

训练 Agent

让训练流程，成为可复用的方法。

从候选图、配对与打标，到配置、执行和产物检查，组织每一步训练工作。

模型训练是一串相互依赖的工作：素材准备、配对、标签、配置、任务执行和结果检查。我把经验整理为阶段规则，并用 Python 工具处理其中重复、容易出错的部分。

参与角色
流程设计 / 数据集工具 / 训练编排
技术与方向
Python / Agent / AI Toolkit / ComfyUI

已形成数据集 WebUI、配对与配置脚本，以及分阶段的训练执行规范。下方视觉案例展示我的模型与工作流实践。

01

数据集工厂

从模板定稿、分身份候选图生成，到增量补跑、批量打标和 R/T 数据集打包。

配对必须能被验证

R 原图、T 目标图与同名标签保持对应，检查缺失、数量和数据结构。

02

保留关键人工判断

模板确认和数据筛选由人把关；流程记录输入、输出、数量、状态与下一步。

阶段之间有清晰交接

将“正在准备”“可以训练”和“产物已验收”区分，避免仅凭进程状态判断成功。

03

组织训练与交付

连接配置生成、上传核验、训练监控、结果下载及工作流交接，按阶段保留执行记录。

训练后继续看效果

结合 Loss、不同 checkpoint 的样图和具体人物效果做选择，再接入 ComfyUI 工作流。

让每一步都有清晰的去向。

从输入到产出，保留必要的检查、状态与记录。
